# 04 — 查看 AI 信號

> AQTMS 嘅核心：多 AI 協作評分 → 自動觸發交易

---

## AI Signals 頁面（/ai-signals）

**需要 ANALYST 或以上權限**

導航到 **AI Signals** 頁面，你會見到：

### 信號列表
每條新聞顯示：
- 📡 **來源**：TELEGRAM / X（Twitter）/ ONCHAIN
- 📊 **綜合評分**（compositeScore）：0-100
- 🔍 **各項分數**：Truth / Sentiment / Relevance
- 🏷️ **狀態標籤**：
  - 🟢 STRONG（≥ 80）— 觸發交易
  - 🟡 MODERATE（60-79）— 僅記錄
  - 🔴 WEAK（< 60）— 忽略

### 評分顏色
| 分數 | 顏色 | 動作 |
|------|------|------|
| ≥ 80 | 🟢 綠色 | **自動觸發交易** |
| 60-79 | 🟡 黃色 | 記錄，不執行 |
| < 60 | 🔴 紅色 | 忽略 |

---

## 查看詳細分析

點擊信號右側 📋 圖標 → 右側彈出 **Detail Drawer**

### AI 模型共識
每個信號經過 3 個階段處理：

| 階段 | 負責 AI | 功能 |
|------|---------|------|
| **Verify** | Grok（首選） | 驗證新聞真假 |
| **Score** | Gemini（首選） | 情感分析 + 相關性評分 |
| **Decide** | DeepSeek（首選） | 綜合判斷 → 交易決策 |

詳細分析顯示：
- 每個 AI 模型嘅評分 + 理由
- 建議操作（BUY / SELL / HOLD）
- 受影響資產列表（BTC、ETH、SOL...）
- 緊急程度（LOW / MEDIUM / HIGH / CRITICAL）
- 共識水平（HIGH / MEDIUM / LOW）

### 綜合評分計算
```
Composite Score =
  Truth × 0.35
  + |Sentiment| × 0.15
  + Relevance × 0.40
  + Confidence × 0.10
```

---

## 自動交易流程

```
新聞來源（Telegram / X）
    ↓
Bee-Queue: news:process
    ↓
AI Pipeline: Grok → Gemini → DeepSeek
    ↓ (compositeScore ≥ 80)
Bee-Queue: trade:execute
    ↓
Risk Engine 檢查
    ↓ (風險通過)
Exchange API 下單
    ↓
WebSocket 推送 order:update
```

> 💡 **提示**：如果 AI 信號出咗但冇自動交易，檢查：
> 1. 評分是否 ≥ 80
> 2. 是否有 CONNECTED 嘅交易所
> 3. 風險規則是否通過

---

## 篩選與監控

- 系統每 **15 秒**自動刷新最新信號
- 可用 Source filter 睇特定來源
- 可用 minScore filter 只睇高分信號（e.g. ≥ 70）

---

## 常見錯誤

| 錯誤 | 原因 | 解決方法 |
|------|------|----------|
| 冇信號顯示 | 冇 Data Source 運行 | 設定 Telegram Bot / X API |
| 信號有但冇交易 | Score < 80 或冇交易所連接 | 檢查評分 + 交易所狀態 |
| AI 分析顯示 "No AI available" | 冇 AI Provider API Key | 設定 OPENAI_API_KEY 等環境變數 |
| 信號延遲 | Queue 堆積 | GET /health 檢查 queue 狀態 |
