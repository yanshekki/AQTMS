# 07 — 常見問題

---

## 帳戶與登入

### Q: 忘記登出會點？
A: JWT Token 有 7 天有效期，過期後自動登出。唔需要手動登出。

### Q: 支援咩錢包？
A: MetaMask、Brave Wallet、Rabby、Coinbase Wallet、WalletConnect、Trust Wallet。

### Q: 可以同時用多個錢包登入嗎？
A: 每個錢包地址對應一個獨立帳戶。切換錢包需要重新登入。

### Q: 點樣升級權限？
A: 聯絡系統管理員（ADMIN / SUPER_ADMIN），佢哋可以去 Admin Panel → User Management 修改角色。

## 交易所連接

### Q: 點樣切換到紙上交易模式？
A: 唔連接真實交易所就得 — 系統喺冇交易所時唔會執行真實交易。亦可以將 maxPositionSize 設為 0。

### Q: 支援邊啲交易所？
A: Binance、Bybit（已實現）、Futu、IBKR（Adapter 已定義，待配置）、Uniswap V3、PancakeSwap、Raydium（DEX，已定義）。

### Q: API Key 安全性？
A: 所有 API Key 使用 **AES-256-GCM** 加密儲存。解密僅喺初始化 Adapter 時短暫進行，用完即棄。加密密鑰（ENCRYPTION_KEY）儲存喺伺服器環境變數，唔會出現喺程式碼或日誌中。

### Q: 點樣刪除已連接嘅交易所？
A: Exchanges 頁面 → 點擊 ExchangeCard 上嘅刪除按鈕 → 確認。

### Q: API Key 權限應該點設定？
A: 最少需要：
- ✅ **Enable Reading**（讀取餘額/持倉）
- ✅ **Enable Spot Trading**（下單/取消）
- ❌ **Disable Withdrawals**（絕對唔好開）
- ❌ 唔需要 Futures / Margin 權限

## AI 與交易

### Q: AI 信號有延遲？
A: 正常。新聞從來源 → Queue → AI 評分 → Trade Queue 有一條 pipeline，平均延遲 1-5 秒。

### Q: 可以只睇信號唔自動交易嗎？
A: 可以。將 Scoring Rules 嘅 action 設為「ALERT」而非「BUY/SELL」。

### Q: AI 評分唔準？
A: AI 評分僅供參考，唔構成投資建議。建議先用回測驗證策略表現。

### Q: 支援邊啲 AI 模型？
A: OpenAI (GPT-4o)、DeepSeek (Chat)、Grok (Grok-2)、Gemini (Flash)、Ollama (Llama 3.2 Local)。

### Q: 可以只用一個 AI 模型嗎？
A: 可以。只需設定該模型嘅 API Key，其他留空即可。系統會自動降級到可用模型。

## 風險管理

### Q: 風險規則觸發後會點？
A: 系統會拒絕該筆交易，並在 Risk Dashboard 顯示違規原因 + 建議倉位大小。

### Q: 每日虧損限額點計？
A: 由當日 00:00 UTC 起計嘅累計已實現虧損。超過限額後當日唔會再執行新交易。

### Q: 點樣設定 Stop Loss？
A: 目前通過風險規則嘅 maxLossPerTradePercent 控制。自動 Stop Loss 功能將在 Phase 2 加入。

## 回測

### Q: 回測結果同真實交易有差異？
A: 正常。回測無法完全模擬：
- 真實滑點（Slippage）
- 流動性不足
- 交易所延遲
- 市場衝擊成本

建議喺回測中設定 **0.1% 以上 slippage** 作為安全邊際。

### Q: 回測支援咩策略？
A: 目前支援 MA Cross（均線交叉）同 Score Threshold。自訂策略可以擴展 BacktestService。

### Q: 回測數據來源？
A: Binance 公開 API（/api/v3/klines），唔需要 API Key。數據為 1h Klines。

## 技術問題

### Q: 系統需要咩硬件？
A: 最低：2 CPU / 4GB RAM / 20GB SSD。建議：4 CPU / 8GB RAM / 50GB SSD。

### Q: 支援咩數據庫？
A: MySQL 8+（必須）、Redis 7+（必須）。

### Q: 可以 Self-host 嗎？
A: 可以。見 [deployment.md](deployment.md) — 支援 Docker Compose + Kubernetes。

### Q: 支援咩語言？
A: English + 繁體中文（zh-HK）。

### Q: 遇到 Error 點算？
A: 
1. 檢查 `/health` endpoint
2. 檢查 `/metrics` Prometheus 指標
3. 查看 backend logs
4. 檢查 Redis + MySQL 連線
5. 提交 GitHub Issue

### Q: Log 喺邊度？
A: Backend logs 輸出到 stdout（Docker logs / K8s logs）。使用 Pino logger，支援結構化 JSON 格式。

## 安全

### Q: 系統有冇做 Rate Limiting？
A: 有。一般 API 100 req/min、Auth 10 req/min、Trade 30 req/min。

### Q: 支援 2FA 嗎？
A: Wallet 簽名本身就係 2FA（需要擁有私鑰先簽到名）。傳統 2FA 將在 Phase 2 加入。

### Q: 數據會備份嗎？
A: 建議每日 MySQL dump + Redis AOF 備份。見 [deployment.md](deployment.md) 備份章節。
