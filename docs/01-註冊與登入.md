# 01 — 註冊與登入

> AQTMS 使用 Wallet 簽名認證，免密碼、免 Gas、免 Email

---

## 步驟

### 1. 打開 AQTMS
瀏覽器打開 AQTMS 首頁，你應該見到：

- 🏦 AQTMS Logo（頂部置中）
- "Automated Quantitative Trading Management System" 副標題
- **「Connect Wallet to Login」** 按鈕

### 2. 連接錢包
點擊 **「Connect Wallet to Login」**，系統會彈出錢包選擇視窗。

**支援嘅錢包**：
- 🦊 MetaMask（瀏覽器插件）
- 🦁 Brave Wallet（內建）
- 🔗 WalletConnect（手機掃碼）
- 🪙 Coinbase Wallet

選擇你嘅錢包 → 錢包會顯示簽名請求。

### 3. 簽名驗證
錢包會顯示一段簽名訊息：
```
AQTMS Login
Wallet: 0x1234...5678
Nonce: abc123def456...
```

點擊 **「Sign」**（簽名）。

> ⚠️ **注意事項**：
> - 簽名**不會消耗任何 Gas**，只是用嚟驗證你嘅錢包所有權
> - 系統**唔會儲存你嘅私鑰**，私鑰永遠留喺你嘅錢包
> - 簽名訊息無法被其他人重放（每次 nonce 唔同）

### 4. 登入完成
簽名成功後：
- ✅ 自動跳轉到 **Dashboard**
- ✅ 右上角顯示你嘅角色標籤（VIEWER / TRADER / ANALYST / ADMIN）
- ✅ 右上角顯示 Wallet Address（縮寫格式）

---

## Dashboard 預覽

登入後你會見到 Dashboard，包含：
| Widget | 說明 |
|--------|------|
| Total Portfolio Value | 總資產價值（連接交易所後顯示） |
| Today P&L | 今日盈虧 |
| Latest AI Signal | 最新 AI 信號 |
| Open Positions | 當前持倉數量 |
| Risk Score | 風險分數（0-100） |
| Sharpe Ratio | 夏普比率 |

> 💡 **提示**：Dashboard 數據需要連接交易所後先會顯示真實數字。

---

## 常見錯誤

| 錯誤 | 原因 | 解決方法 |
|------|------|----------|
| "No wallet detected" | 瀏覽器冇裝錢包插件 | 安裝 MetaMask 或使用 Brave 瀏覽器 |
| "Signature verification failed" | 簽名內容被篡改或錢包地址不符 | 重新點擊「Connect Wallet to Login」 |
| "User not found" | 錢包地址未在系統註冊 | 正常 — 首次登入會自動建立帳戶 |
| Gas fee warning | 某些錢包會顯示 Gas 估算 | 忽略即可 — 簽名唔需要 Gas |

## 權限與角色

首次登入嘅用戶預設為 **VIEWER** 角色，可以：
- ✅ 查看 Dashboard
- ✅ 查看 Settings
- ✅ 查看 Exchange 狀態（唯讀）

如需升級權限（TRADER / ANALYST / ADMIN），請聯絡系統管理員。
