# 02 — 連接交易所

> 將你嘅交易所帳戶連接到 AQTMS，實現自動化交易

---

## 步驟

### 1. 準備 API Key

**Binance**：
1. 登入 Binance → 右上角 Profile → **API Management**
2. 點擊 **「Create API」** → 選擇 **「System Generated」**
3. 設定 API Key 權限：
   - ✅ **Enable Reading**（讀取餘額、持倉）
   - ✅ **Enable Spot & Margin Trading**（現貨交易）
   - ❌ **Disable Withdrawals**（關閉提現 — 非常重要！）
   - ❌ Disable Futures / Margin（唔需要）
4. 完成安全驗證 → **複製 API Key + Secret**

> ⚠️ **安全警告**：
> - **絕對唔好開 Withdrawal 權限**
> - 建議使用**子帳戶**（Sub-account）進行交易
> - 唔好將 API Secret 分享俾任何人
> - API Secret 只會顯示一次，請妥善保存

**Bybit**（步驟類似）：
1. 登入 Bybit → Account → **API Management**
2. Create New Key → 勾選 **Read-Write**（Spot）
3. 關閉 Withdrawal 權限

### 2. 連接 AQTMS

1. 點擊導航欄 **「Exchanges」**
2. 點擊 **「Add Connection」** 按鈕
3. 在彈出嘅視窗中：
   - **Exchange**：選擇 `BINANCE` 或 `BYBIT`
   - **API Key**：貼上你複製嘅 API Key
   - **API Secret**：貼上你複製嘅 API Secret
4. 點擊 **「Connect」**

### 3. 驗證連接

連接後系統會**自動測試**連接：

| 狀態 | 含義 |
|------|------|
| 🟢 **Connected** | 連接成功，API Key 有效 |
| 🔴 **Error** | 連接失敗，檢查 API Key 權限或網絡 |
| 🟡 **Testing** | 正在測試中... |

成功連接後，ExchangeCard 會顯示：
- 交易所名稱（BINANCE / BYBIT）
- 連接狀態
- 可用餘額

---

## 加密與安全

AQTMS 使用 **AES-256-GCM** 加密儲存你嘅 API Key：

```
你的 API Key → AES-256-GCM 加密 → 密文儲存喺 DB
解密只喺建立交易連線時暫時進行 → 用完即棄
```

- 🔒 API Key **永遠唔會以明文儲存**
- 🔒 加密密鑰（ENCRYPTION_KEY）只存在於伺服器環境變數
- 🔒 所有 API 請求經 HTTPS + JWT 驗證

---

## 常見錯誤

| 錯誤 | 原因 | 解決方法 |
|------|------|----------|
| 「API Key 無效或權限不足」 | API Key 權限唔夠 | 返去 Binance 檢查 Enable Reading + Spot Trading |
| 「Connection test failed」 | 網絡問題或 API Key 已過期 | 檢查 IP 白名單設定，或重新建立 API Key |
| 「Exchange account not found」 | Exchange ID 不存在 | 重新 Add Connection |
| 餘額顯示 0 | 子帳戶無資金或 API Key 權限不足 | 確認子帳戶有 USDT + Enable Reading 已開啟 |

---

## 管理交易所連接

- **測試連接**：點擊 ExchangeCard 上嘅 Test 按鈕
- **查看餘額**：ExchangeCard 自動顯示
- **刪除連接**：點擊刪除按鈕 → 確認 → API Key 從系統移除

> 💡 **提示**：建議先用子帳戶 + 小額資金（200-500 USDT）測試，確認一切正常後再連接主帳戶。
