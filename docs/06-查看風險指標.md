# 06 — 查看風險指標

> 實時監控你嘅投資組合風險

---

## Risk Dashboard（/risk）

**需要 TRADER 或以上權限**

打開 **Risk** 頁面，你會見到全面嘅風險儀表板：

### 頂部：Risk Score
- 大數字 0-100
- 🟢 綠色（≤ 30）：低風險 — 可以繼續交易
- 🟡 黃色（31-60）：中等風險 — 注意倉位
- 🔴 紅色（> 60）：高風險 — 建議減倉或對沖

### 風險指標卡（6 張）

| 指標 | 說明 | 解讀 |
|------|------|------|
| **VaR 95%（1-Day）** | 95% 信心下，1 日最大潛在虧損 | 數字越大風險越高 |
| **VaR 99%（1-Day）** | 99% 信心下嘅極端風險 | 極端行情預警 |
| **CVaR 95%** | 超過 VaR 時嘅平均虧損 | Tail risk 指標 |
| **Max Drawdown** | 歷史最大回撤 % | >20% 需警惕 |
| **Concentration Risk** | 集中度風險等級 | CRITICAL 需立即調整 |
| **Sharpe Ratio** | 風險調整回報 | >2 優秀 |

### 集中度風險
每個資產顯示：
- 資產名稱 + 持倉佔比（%）
- 進度條（顏色對應風險等級）
- CRITICAL（紅色）→ 超過單一資產上限 150%

### Beta 暴露
每個資產顯示相對 BTC/ETH 嘅 Beta 值：
- β > 1.5 🔴：高波動 → 顯示對沖建議
- 0.5 < β < 1.5 🟡：中等波動
- β < 0.5 🟢：低波動

點擊對沖建議可以**複製建議倉位**到剪貼簿。

### Correlation Matrix（相關性矩陣）
熱力圖顯示資產間嘅相關性：
- 🔴 紅色：正相關（資產同漲同跌）
- 🟢 綠色：負相關（可以對沖）
- 數值範圍：-1（完全負相關）到 +1（完全正相關）

### Risk Alerts（底部）
顯示最近觸發嘅風險違規：
| Rule | Status | Action |
|------|--------|--------|
| Max single asset exceeded | BREACHED | Reduce BTC position |
| Daily loss limit | WARNING | Trading paused |

點擊 Action 按鈕可以**複製建議行動**。

## Portfolio 頁面（/portfolio）

**需要 TRADER 或以上權限**

### 頂部
- **Total Portfolio Value**：總資產價值
- **Today P&L**：今日盈虧（綠色 + / 紅色 -）
- **MTD / YTD Return**：月/年回報

### 資產分配
- 🥧 **Pie Chart**：按資產類型分色
- 點擊餅圖 sector 可以 filter 下方表格
- **Top 5 持倉**：Asset / Value / Allocation% / P&L

### 表現曲線
- 📈 **Area Chart**：30 天 / 90 天 / 1 年 toggle
- Hover 顯示詳細數據（Tooltip）

### 表現排名
按 P&L% 排序嘅持倉表現表

- Risk Score（實時更新）

- Latest AI Signal 評分

## 常見錯誤

| 錯誤 | 原因 | 解決方法 |
|------|------|----------|
| 風險分數一直 0 | 冇連接交易所 / 冇持倉 | 連接交易所 + 建立持倉 |
| VaR 顯示異常大 | 歷史數據不足 | 等待更多交易日數據 |
| 相關性矩陣空白 | 少於 2 個資產 | 增加資產多樣性 |
| 風險指標冇更新 | 15 秒 refresh cycle | 等一陣或手動刷新 |

---

## 風險管理最佳實踐

1. **每日檢查 Risk Score**：確保喺 50 以下
2. **單一資產唔超過 25%**：避免集中風險
3. **Max DD 超過 20% → 立即減倉**
4. **定期 Review Beta 暴露**：確保對沖有效
5. **使用 Stop Loss**：每筆交易設定止損
