# 05 — 執行回測

> 用真實歷史數據驗證你嘅交易策略

---

## Backtest 頁面（/backtest）

**需要 ANALYST 或以上權限**

導航到 **Backtest** 頁面：

### 策略參數（左側面板）

| 參數 | 說明 | 範例 |
|------|------|------|
| **Symbol** | 交易對 | BTCUSDT |
| **Start Date** | 回測開始日期 | 2025-01-01 |
| **End Date** | 回測結束日期 | 2025-04-01 |
| **Initial Capital** | 初始資金（$） | 10000 |
| **Fee Rate** | 手續費率 | 0.1% |
| **Slippage** | 滑點 | 0.05% |
| **Fast MA** | 快線週期（MA Cross） | 9 |
| **Slow MA** | 慢線週期（MA Cross） | 21 |

點擊 **「Run Backtest」** 執行。

---

## 策略說明

### MA Cross（均線交叉）
- **Golden Cross**：快線（9）向上穿越慢線（21）→ **買入**
- **Death Cross**：快線（9）向下穿越慢線（21）→ **賣出**

適合趨勢市，震盪市表現較差。

### Score Threshold（評分閾值）
- Random score > 80 → 買入
- Random score < 20 → 賣出

用於模擬 AI 信號觸發策略。

## 回測報告

執行後右側顯示完整報告：

### 關鍵指標
| 指標 | 優秀 | 一般 | 需改進 |
|------|------|------|--------|
| **Total Return** | > 50% | 10-50% | < 10% |
| **Win Rate** | > 60% | 45-60% | < 45% |
| **Sharpe Ratio** | > 2.0 | 1.0-2.0 | < 1.0 |
| **Sortino Ratio** | > 2.5 | 1.5-2.5 | < 1.5 |
| **Calmar Ratio** | > 1.0 | 0.5-1.0 | < 0.5 |
| **Max Drawdown** | < 10% | 10-25% | > 25% |
| **Profit Factor** | > 2.0 | 1.5-2.0 | < 1.5 |

### 圖表
- **Equity Curve**：資金曲線圖（藍色）
- **Drawdown Curve**：回撤圖（紅色）

### 交易列表
顯示最近 20 筆交易：
- 時間 / Side / Price / PnL / Reason（買入/賣出原因）

## 回測技巧

1. **先用長週期測試**：3-6 個月數據，涵蓋不同市場環境
2. **對比不同參數**：調整 MA 週期，睇邊個組合表現最好
3. **關注 Drawdown**：唔好只睇 Return，Max DD 同樣重要
4. **設定充足 Slippage**：真實交易會有滑點，回測應設定 0.05-0.1%

> 💡 **提示**：回測使用 Binance 公開 API（不需 API Key），數據為 1h Klines。

---

## 常見錯誤

| 錯誤 | 原因 | 解決方法 |
|------|------|----------|
| "Insufficient data" | 時間範圍內冇足夠 Kline | 擴大日期範圍或選擇主流交易對 |
| 回測結果異常好 | 過擬合（Overfitting） | 用不同時間段交叉驗證 |
| 真實交易與回測差異大 | 滑點、流動性、延遲 | 回測中設定更高的 Slippage |
| "Binance API error" | 請求過多或網絡問題 | 等一陣再試 |
