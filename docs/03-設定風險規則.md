# 03 — 設定風險規則

> 專業風險控制係 AQTMS 嘅核心 — 正確設定可以保護你嘅資金

---

## 風險儀表板（/risk）

打開 **Risk** 頁面，你會見到：

### 風險分數
- 大數字顯示 0-100 綜合風險分數
- 🟢 0-30：低風險
- 🟡 31-60：中等風險
- 🔴 61-100：高風險

### 風險指標
| 指標 | 說明 |
|------|------|
| **VaR 95%** | 95% 信心水平下，1 日內最大潛在虧損 |
| **VaR 99%** | 99% 信心水平下嘅極端風險 |
| **CVaR** | Conditional VaR — 超過 VaR 時嘅平均虧損 |
| **Max Drawdown** | 歷史最大回撤（%） |
| **Sharpe Ratio** | 風險調整後回報（>1 良好，>2 優秀） |

### 集中度風險
顯示每個資產嘅持倉佔比：
- 🟢 LOW：低於上限 70%
- 🟡 MEDIUM：接近上限（70-100%）
- 🔴 HIGH：超過上限
- 🔴 CRITICAL：超過上限 150%

### Beta 暴露
顯示每個資產相對 BTC/ETH 嘅波動倍數：
- β > 1.5：高波動 → 建議對沖
- β < 0.5：低波動 → 防禦性強

## 評分規則設定（/scoring-rules）

**需要 ANALYST 或以上權限**

### 權重設定

AI 綜合評分由 4 個維度加權計算：

| 維度 | 說明 | 建議權重 |
|------|------|----------|
| **Truth** | 新聞真實性（Grok 驗證） | 35% |
| **Sentiment** | 市場情緒（Gemini 分析） | 15% |
| **Relevance** | 交易相關性 | 40% |
| **Confidence** | AI 信心度 | 10% |

> ⚠️ **注意**：4 個權重**加埋必須等於 100%**，否則系統會顯示紅色警告。

### 觸發閾值

| 閾值 | 效果 |
|------|------|
| **≥ 80** | 強信號 — 自動觸發交易（建議） |
| **60-79** | 中等信號 — 僅記錄提示 |
| **< 60** | 弱信號 — 忽略 |

### 交易動作
每個規則可以選擇觸發後嘅動作：
- **BUY**：自動買入
- **SELL**：自動賣出
- **ALERT**：僅發送通知，不執行交易
- **IGNORE**：完全忽略

## 倉位計算

AQTMS 支援 4 種倉位算法（POST /api/v1/risk/position-size）：

| 算法 | 適合 | 公式 |
|------|------|------|
| **Half Kelly** | 一般交易者 | f* = (p×b - q)/b × 0.5 |
| **Fixed Fractional** | 保守型 | 每筆風險固定 % |
| **Fixed Ratio** | 穩健增長 | 按帳戶增長動態調整 |
| **ATR Adjusted** | 技術分析 | 按波動率（ATR）調整倉位 |

## 推薦風險參數

### 保守型（適合新手 / 小資金）
| 參數 | 值 |
|------|-----|
| 單筆最大風險 | 1% |
| 單日最大虧損 | 3% |
| 最大總倉位 | 50% |
| 單一資產上限 | 15% |
| 倉位算法 | Fixed Fractional |
| 信號閾值 | ≥ 85 |

### 一般型（適合有經驗交易者）
| 參數 | 值 |
|------|-----|
| 單筆最大風險 | 2% |
| 單日最大虧損 | 5% |
| 最大總倉位 | 80% |
| 單一資產上限 | 25% |
| 倉位算法 | Half Kelly |
| 信號閾值 | ≥ 80 |

### 進取型（適合高風險承受能力）
| 參數 | 值 |
|------|-----|
| 單筆最大風險 | 5% |
| 單日最大虧損 | 10% |
| 最大總倉位 | 100% |
| 單一資產上限 | 40% |
| 倉位算法 | ATR Adjusted |
| 信號閾值 | ≥ 75 |

> ⚠️ **風險提醒**：回測顯示進取型設定在極端行情下可能導致 50%+ 回撤。建議先用保守設定，觀察表現後逐步調整。

---

## 常見錯誤

| 錯誤 | 原因 | 解決方法 |
|------|------|----------|
| 風險規則無效 | 參數超出範圍 | 檢查百分比設定（1-100%） |
| 所有交易被拒絕 | 風險規則太嚴格 | 放寬單筆/單日上限 |
| 評分規則不生效 | 規則狀態為 Draft | 切換為 Active |
